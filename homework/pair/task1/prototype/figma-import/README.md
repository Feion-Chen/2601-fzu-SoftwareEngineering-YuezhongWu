# 导入 Figma 并创建在线原型

## 一、导入页面

1. 登录 Figma，新建一个 Design file。
2. 将本目录中的 6 个 SVG 文件全部拖入 Figma 画布。
3. 每个 SVG 会成为一个 390 × 844 的页面 Frame。
4. 将 Frame 按以下顺序排列：
   - 01-home.svg
   - 02-search.svg
   - 03-detail.svg
   - 04-publish.svg
   - 05-success.svg
   - 06-my-posts.svg

## 二、建立交互连接

切换到 Figma 右侧的 Prototype 面板，按以下关系连接：

| 起点页面 | 点击区域 | 目标页面 |
| --- | --- | --- |
| 01 首页 | 搜索框 | 02 搜索 |
| 01 首页 | 任意信息卡片 | 03 信息详情 |
| 02 搜索 | 任意搜索结果 | 03 信息详情 |
| 03 详情 | 联系发布者 | 03 详情，显示提示或弹窗 |
| 01 首页 | ＋发布 | 04 发布信息 |
| 04 发布信息 | 确认发布 | 05 发布成功 |
| 05 发布成功 | 查看我的发布 | 06 我的发布 |
| 06 我的发布 | 查看详情 | 03 信息详情 |
| 06 我的发布 | 标记为已找到 | 保持当前页面，更新状态 |

如果没有制作弹窗，可以暂时让“联系发布者”连接回详情页。

## 三、获取在线链接

1. 点击右上角 Share。
2. 将链接权限设置为“Anyone with the link can view”。
3. 切换到 Prototype 视图。
4. 点击 Present，复制浏览器地址栏中的原型展示链接。
5. 将链接填写到博客稿和项目 README 中。
