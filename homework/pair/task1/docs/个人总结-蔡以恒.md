# 蔡以恒个人总结

本次结对作业中，我主要负责首页、搜索页面、信息详情页面和流程图设计。以前我容易把原型理解成“画好看的界面”，但这次通过需求分析，我认识到原型首先要让用户看懂信息之间的关系和操作顺序。

在与陈飞扬合作的过程中，我们一起检查了“查看信息”和“发布信息”两条流程。我们发现首页不能只放卡片，还需要明显的搜索入口；详情页不能把联系方式放在页面很底部，否则用户不容易找到。因此我们将联系方式放在固定按钮中，并把物品名称、地点、时间等关键信息放在首屏。

我在本次作业中主要学会了流程图和页面结构的对应关系。流程图中的每一步都应该能在原型中找到对应页面和操作，否则说明功能设计不完整。通过反复检查，原型从最初的多页面结构简化为首页、搜索、详情、发布、发布成功和我的发布六个页面，流程更清楚，也更容易实现。

遇到的问题：搜索页面一开始设计了太多的筛选条件，后来我们只保留类型和地点，让用户可以在两步内完成搜索。这个调整让我理解了“简单”并不是功能少，而是用户完成核心任务时不需要思考太多。
