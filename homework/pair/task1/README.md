## 项目目标

本项目面向校园失物招领场景，围绕“发布信息、浏览信息、搜索物品、查看详情、联系发布者、修改状态”等核心任务，完成第一次结对作业的需求分析和原型设计。本次不编写程序代码，设计结果将作为第二次结对作业的基础。

## 交付内容

- 需求分析：用户角色、主要问题、功能范围、业务流程和非功能需求。
- 原型设计：首页、搜索、详情、发布、发布成功、我的发布等页面。
- 流程图：浏览详情流程、发布成功流程。
- 博客材料：800—1200 字博客稿、PSP 表、结对过程，以及陈飞扬版个人总结。
- Figma 素材：可直接导入 Figma 的 6 个 SVG 页面。

## 原型范围

1. 首页：浏览全部、寻物和招领信息。
2. 搜索：按关键词、类型和地点筛选信息。
3. 详情：查看物品描述、地点、时间和联系方式。
4. 发布：填写寻物或招领信息。
5. 发布成功：确认发布结果并进入我的发布。
6. 我的发布：查看自己发布的信息并修改状态。
