## 5. 手工测试建议

自动测试已经覆盖核心规则，但提交前仍建议本人实际完成以下操作：

1. 从开始界面依次进入三个关卡。
2. 观察成功飞出与受阻时的动画区别。
3. 每关至少故意触发一次失误。
4. 使用“重新开始”确认布局恢复。
5. 完成第一关并点击“进入下一关”。
6. 使用 `H`、`U`、`R` 和 `Esc` 快捷键。

手工测试后的真实结果可以补充到本报告中，也可以直接写入博客。
